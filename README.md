Пусть $k$ — произвольное поле характеристики нуль, $L$ — конечномерная
разрешимая алгебра Ли над $k$, а $M$ — конечномерная алгебра Ли над $k$.
Если существует изоморфизм ассоциативных $k$-алгебр с единицей

```math
\Phi\colon U_k(L)\xrightarrow{\sim}U_k(M),
```

то существует $k$-линейная биекция $f\colon L\to M$, удовлетворяющая

```math
f([x,y]_L)=[f(x),f(y)]_M\qquad\text{для всех }x,y\in L.
```
